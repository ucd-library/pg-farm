# Documentation

Welcome to the PG Farm documentation. PG Farm is a hosted PostgreSQL platform provided by the UC Davis Library. Use the links below to find the guide you need.

- [Login Help](/docs/authenticate) — How to log in and get a token to access a database, using the desktop application or the CLI.
- [Service Account Authentication](/docs/authenticate-service-account) — How to request and use a service account to connect an application or script to PG Farm without an interactive login.
- [Public User Account Access](/docs/public-user-account) — How to connect to databases with public access enabled using the read-only public user account.
- [HTTP REST API Access](/docs/http-rest-api) — How to query PG Farm databases over HTTP using the auto-generated PostgREST API.
